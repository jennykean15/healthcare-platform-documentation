# Quick Start Guide

## Overview

This guide explains how to access and begin using the fictional Healthcare Claims Processing Platform (HCPP).

HCPP allows authorized healthcare users to submit, review, and manage healthcare claims through a centralized platform.

## Prerequisites

Before getting started, confirm that you have:

- An active HCPP user account
- Access to your organization's claims environment
- A supported web browser
- Appropriate permissions for your assigned role

## Sign In

1. Open the HCPP sign-in page.
2. Enter your assigned username and password.
3. Select **Sign In**.
4. Complete multi-factor authentication when prompted.
5. Confirm that the HCPP dashboard appears.

> **Note:** Available dashboard options depend on your assigned permissions.

## Submit a Claim

1. From the HCPP dashboard, select **Claims**.
2. Select **New Claim**.
3. Enter the required member and provider information.
4. Add the applicable diagnosis and procedure codes.
5. Review the claim information for accuracy.
6. Select **Submit Claim**.

After submission, HCPP assigns the claim a unique identification number and displays the current processing status.

## Check Claim Status

1. Select **Claims** from the dashboard.
2. Enter the claim identification number in the search field.
3. Select **Search**.
4. Review the displayed claim status.

Common statuses include:

| Status | Description |
| --- | --- |
| Submitted | Claim was successfully received. |
| Processing | Claim is undergoing validation and processing. |
| Action Required | Additional information or correction is required. |
| Completed | Claim processing is complete. |

## Troubleshooting

If you cannot access the platform or submit a claim:

1. Confirm your internet connection.
2. Verify that your username and password are correct.
3. Confirm that your account has the required permissions.
4. Review all required claim fields for missing information.
5. Record any displayed error message or error code.

For additional troubleshooting, see the **Troubleshooting Guide**.

## Next Steps

After completing this guide, you should be able to:

- Access the HCPP platform
- Navigate the claims dashboard
- Submit a basic healthcare claim
- Locate an existing claim
- Interpret basic claim statuses

Continue to the **How-To Guides** for detailed instructions on specific platform tasks.
